# Answer assessment protocol

Before collecting drafts, we sorted the 31 held-out naturalization questions by ID and sampled 20 with `random.Random(72).sample`. We kept the sample order and added five [out-of-scope questions](out_of_scope.jsonl). The [selection manifest](selection_manifest.json) records the IDs and input hashes. The selected questions had no exact matches in the recorded generation development cases. Topics and source documents could overlap.

We ran the same 25 questions through both pipelines. Both used the same Qwen model, prompt instructions, and [generation settings](frozen_configuration.json). Each pipeline supplied its own retrieved passages. We kept dataset reference answers and source-review notes and excerpts out of the prompts. The [saved records](responses/) preserve the first attempts, exact inputs, raw and displayed outputs, and application statuses.

OpenAI Codex checked whether the supplied passages could answer each question. It then assessed each displayed draft against those passages and [verified USCIS material](../source-verification/FINAL_VERIFICATION.md). A supported useful draft answers the question, supports its material claims, uses relevant citations, and preserves essential conditions. The scoring dimensions were factual support, citation relevance, coverage, conditions and exceptions, and plain-English readability. Each used a 0–2 scale for substantive displayed drafts.

The assessment distinguishes partial and incorrect drafts, appropriate and unnecessary declines, validation failures, and execution failures. Rejected raw text provides diagnostic evidence and does not count as a displayed answer. The denominator is 20 per method for naturalization questions and five per method for out-of-scope questions. See the [ratings and reasons](assessment/ratings.csv) and [reviewer metadata](assessment/assessment_metadata.json).
