# USCIS HTML redaction record

We found 39 copies of one Google API key-shaped value in captured USCIS HTML: 16 files in `current_pages/`, seven in `assisted_reference_verification/live_pages/`, and 16 in `final_reference_verification_2026-11-15/live_pages/`. In every file it was the value of the USCIS Drupal setting `uscis_design.apiKey_aao_pm_search`. The app, environment files, and setup script do not use the value. The setting name now appears only in the sanitizer and page-capture code that redact it; no runtime component reads it.

On November 15, 2026, we fetched the official page [Chapter 7 - Revocation of Naturalization](https://www.uscis.gov/policy-manual/volume-12-part-i-chapter-7) directly. Its Drupal settings contained the same setting and value as the captured page. This confirms the value came from publicly served USCIS page configuration. It does not establish who owns the Google project, whether the value is valid, what restrictions it has, or whether it has been revoked. We did not test it against Google APIs.

The 39 published HTML files are sanitized derivatives. We replaced only the value of that setting and added a short HTML comment label. We compared extracted main-page text and all anchor links before and after; both were unchanged. The question, response, ratings, and evaluation outputs remain unchanged. Earlier review tables retain the original capture hashes; use `redaction_manifest.json` to map those hashes to the published derivatives. Capture logs now distinguish the original hash from the derivative hash. The manifest lists each original and sanitized SHA-256 hash. Exact original HTML files are preserved outside the repository at `~/.local/share/aimigrate-private/uscis-html-originals-2026-11-15/`, with private file permissions.

The capture script now saves original bytes outside the repository before writing a sanitized public copy. It stops if a credential-like value cannot be isolated safely. Run `.venv/bin/python scripts/sanitize_uscis_captures.py` to review and sanitize existing Stage 5 captures. Do not publish raw page downloads.

The original value remains in earlier public Git history. We did not rewrite history because the confirmed source is USCIS’s public page configuration and we have no evidence that it is ours; rewriting history would not establish ownership or revoke it. The value’s owner or status remains unconfirmed. Keep the GitHub alert open until USCIS confirms its intended exposure or status.

GitHub’s documented closure choices are `false_positive`, `wont_fix`, `revoked`, and `used_in_tests`. None is fully supported yet: we cannot claim it is not a credential, accept the risk, say it was revoked, or call it a test secret. If USCIS confirms the setting is intentionally public and not a secret, `false_positive` is the accurate project-level choice. Do not choose `revoked` unless the owner confirms revocation.
